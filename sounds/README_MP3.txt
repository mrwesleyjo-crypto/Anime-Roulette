Drop your own mp3 files in here, named EXACTLY as listed below (all
lowercase, matches case-sensitively on GitHub Pages / Linux servers).
If a file is missing, the game automatically falls back to its built-in
synthesized sound — nothing breaks.

sounds/spin-tick.mp3        -> plays repeatedly while the wheel spins
                                (a short "tick"/"clack" clip works best,
                                it gets replayed many times per spin with
                                decreasing frequency as the wheel slows down)

sounds/reveal-useless.mp3   -> plays when a Useless-rarity fighter is revealed
sounds/reveal-common.mp3    -> Common
sounds/reveal-rare.mp3      -> Rare
sounds/reveal-epic.mp3      -> Epic
sounds/reveal-legendary.mp3 -> Legendary
sounds/reveal-mythic.mp3    -> Mythic (also used for the secret
                                "Ultra Instinct Shaggy" pull)

Tip: keep clips short (under ~1 second for reveal-*, under ~0.2s for
spin-tick) so they don't overlap awkwardly when several fire close together.
