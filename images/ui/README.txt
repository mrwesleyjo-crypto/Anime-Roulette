Drop your VS-screen background image here, named exactly:

  vs-background.png

Any wide (landscape) image works — it gets cropped to fill the battle
popup nicely via CSS background-size: cover, so a roughly 3:2 aspect
ratio (like the blue-vs-red diagonal splash image) looks best.

If this file is missing, the battle popup automatically falls back to
its normal plain layout — nothing breaks.

When it IS present:
- Your whole roster's mini-portraits appear on the left/blue side
- The opponent's portrait appears on the right/red side
- A short slide-in + flash animation plays each time a new match starts
